# AeroMind knowledge base

Project-owned reference notes. The ground-side copilot retrieves short excerpts from these files
(`aeromind.llm.knowledge`) to define terms and state limitations.

These notes describe **how this prototype works**. They are not OEM manuals, not airworthiness or
regulatory guidance, and not certified maintenance data. Nothing here authorises any maintenance action.
